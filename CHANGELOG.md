# Changelog

## 1.0.0 – 2026-11-23

First public version.

- Search view in the NotePlan sidebar with grouped results and highlighted matches.
- Quick-search buttons, filters by date, heading, folder and line type, wildcards `*` and `?`.
- Open notes with a click, ⌥ split view (reused), ⌘ new window, ↑↓ and Enter.
- Schatzkiste: collect results and save them as Markdown (new note, today's note, clipboard).
- Optional Raindrop.io source with favourites.
- NotePlan theme, light and dark. English and German, automatic or set in the settings.
